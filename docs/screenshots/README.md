## Add screenshots to the README

1. Open the app with the complete repository folder available.
2. Use **Reset demo** so the captures show the fictional starting scenario.
3. Save PNG screenshots here using the suggested names.
4. Open the root `README.md`, remove the comment markers around the images you added, and remove their placeholder rows if desired.

From the root README, the image syntax is:

```markdown
![Daily dispatch board](docs/screenshots/board-desktop.png)
```

Use a wide desktop capture and a narrow mobile capture. Keep the interface readable and crop out unrelated browser tabs or desktop content.
